Pokémon Quest → 3MF Converter

Bakes each voxel face's texture color onto a single watertight mesh, written both as a standard 3MF colorgroup (what Bambu Studio's "Standard 3MF Color Parsing" dialog reads) and as Bambu's per-triangle paint_color. Every model is audited for non-manifold edges before you can download it.
