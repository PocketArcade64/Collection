Pokémon Quest → 3MF Splitter

Bakes each voxel face's texture color onto a watertight mesh, written both as a standard 3MF colorgroup (what Bambu Studio's "Standard 3MF Color Parsing" dialog reads) and as Bambu's per-triangle paint_color. Every model is audited for non-manifold edges before you can download it.
Split mode additionally cuts the model into one solid part per color with snap-fit pegs and tenons, so each part prints in a single filament and the pieces push together. Every externally visible triangle is copied through byte-for-byte and checked — connectors are only ever cut into faces the original model already hid.

Split into snap-together parts

A piece that is the same filament as whatever it sits on is always merged — splitting it would buy nothing and it would need a connector it has no room for. The threshold above merges further pieces by size: raise it until the fiddly bits stop being separate. Merged geometry keeps its own paint colour, so on an AMS machine the detail still prints in its own colour.
Every externally visible triangle is copied through byte-for-byte. Pegs and pockets are only ever cut into faces the original model already hid.
